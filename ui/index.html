KiCad AutoRouter — Workflow

Reads .kicad_pcb files and updates PCB trace placement. Stages run top to bottom.
How it works: 1) Drop or load a .kicad_pcb file. 2) Adjust parameters if needed. 3) Click Step placement to run a few iterations — moved parts show in the overlay. 4) Click Accept proposal to commit changes to the board. 5) Repeat steps 3–4 until satisfied. Locked parts (in KiCad) never move.
